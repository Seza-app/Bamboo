# BAMBOO — Create. Trade. Grow.

Mobile-first React + Vite prototype with ten views: Overview, Explore, Create token, Portfolio, Token detail, Trade, Activity, Leaderboard, Learn and Profile.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Safety

All market data, prices, balances, rankings, charts and activity are illustrative demo data. No wallet, payment, KYC, token deployment or real trading is enabled. All trade actions are UI-only.
