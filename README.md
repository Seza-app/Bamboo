# BAMBOO — Create. Trade. Grow.\n\nMobile-first React + Vite prototype with ten views: Overview, Explore, Create token, Portfolio, Token detail, Trade, Activity, Leaderboard, Learn and Profile.\n\nRun with Node.js 20+: `npm install`, `npm run dev`; production build: `npm run build`.\n\nAll market data, prices, balances, rankings, charts and activity are illustrative demo data. No wallet, payment, KYC, token deployment or real trading is enabled.
